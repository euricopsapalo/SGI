# meu-projeto-docker

Projeto com Docker para desenvolvimento com React, NestJS e PostgreSQL.

## Comandos

### Iniciar ambiente
docker-compose up -d

### Parar ambiente
docker-compose down

### Ver logs
docker-compose logs -f

## Acessos
- Frontend: http://localhost:3000
- Backend API: http://localhost:3001
- Adminer: http://localhost:8080
